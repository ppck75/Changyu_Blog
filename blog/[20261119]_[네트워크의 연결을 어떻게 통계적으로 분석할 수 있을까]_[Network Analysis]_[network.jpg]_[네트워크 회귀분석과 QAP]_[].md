# 네트워크 회귀분석과 QAP: 네트워크의 연결은 어떻게 통계적으로 분석할 수 있을까?



*이 글은 Gopal et al.의 「The National Network of US State Legislators on Twitter」를 읽으면서, 연구에 사용된 네트워크 회귀분석(Dyadic Regression)과 QAP(Quadratic Assignment Procedure)의 개념 및 분석 원리를 스스로 공부하고 정리한 내용입니다.*

**참고 논문**

Gopal, I., Kim, T., Nakka, N., Boehmke, F. J., Harden, J. J., & Desmarais, B. A. (2025). The national network of US state legislators on Twitter. *Political Science Research and Methods, 13*(4), 1042–1054.


## 1. 네트워크 회귀분석과 QAP의 전체적인 분석 과정

Gopal et al.(2025)은 미국 주의원들의 Twitter 팔로우(Follower), 리트윗(Retweet), 멘션(Mention) 네트워크를 분석하여 의원 간 연결 형성과 관련되는 요인을 검토했다.

이를 위해 \*\*Dyadic Regression(행위자 쌍 단위 회귀분석)\*\*과 \*\*QAP(Quadratic Assignment Procedure)\*\*를 결합했다.  

연구의 방법론적 절차는 크게 네 단계로 구분할 수 있다.

1. **Network Construction:** 의원 간 팔로우, 리트윗, 멘션 관계를 이용하여 네트워크를 구축한다.
2. **Dyadic Regression:** 의원 간 연결의 존재 여부 또는 상호작용 횟수를 종속변수로 설정하여 회귀분석을 수행한다.
3. **QAP Permutation Test:** 네트워크 관측치 사이에 존재하는 통계적 의존성을 고려하여 회귀계수의 유의성을 검정한다.
4. **Interpretation:** 정당, 성별, 인종, 소속 의회 등의 속성이 의원 간 연결과 어떤 관계를 갖는지 해석한다.

여기서 회귀분석과 QAP가 서로 다른 역할을 한다.

회귀분석은 설명변수와 네트워크 연결 사이의 관계를 추정한다. QAP는 네트워크 자료의 의존성을 고려하여 이러한 관계의 통계적 유의성을 평가한다.

따라서 Gopal et al.(2025)의 방법론은 **Dyadic Regression + QAP-based Statistical Inference**로 정리할 수 있다.

## 2. Directed Dyad: 회귀분석의 단위는 무엇인가?

### 2.1 개인이 아니라 개인 간 관계를 분석한다

일반적인 사회과학 회귀분석에서는 개인이 관측 단위인 경우가 많다.

예를 들어 학력과 소득의 관계를 분석한다면 개인별 학력과 소득이 하나의 관측치가 된다.

| 개인 | 학력   | 소득    |
| -- | ---- | ----- |
| A  | 대졸   | 4,000 |
| B  | 고졸   | 3,000 |
| C  | 대학원졸 | 6,000 |

반면 네트워크 회귀분석에서는 분석 단위를 개별 행위자가 아니라 \*\*두 행위자 사이의 관계(Dyad)\*\*로 설정할 수 있다.

Gopal et al.(2025)은 방향성이 있는 행위자 쌍(Directed Dyad)을 분석 단위로 사용했다.

예를 들어 네 명의 의원 A, B, C, D 사이에 다음과 같은 팔로우 관계가 있다고 가정한다.

```text
A ──────→ B
↑         │ ↑
│         ↓ │
C ←───────  D
```

그림의 연결을 관계별로 명시하면 다음과 같다.

```text
A → B
B → C
C → A
D → B
```

이를 인접행렬(Adjacency Matrix)로 표현하면 다음과 같다.

| 발신 \ 수신 |  A |  B |  C |  D |
| ------- | -: | -: | -: | -: |
| A       |  - |  1 |  0 |  0 |
| B       |  0 |  - |  1 |  0 |
| C       |  1 |  0 |  - |  0 |
| D       |  0 |  1 |  0 |  - |

각 행은 연결을 보내는 의원(Sender), 각 열은 연결을 받는 의원(Receiver)을 의미한다.

- `Y_AB = 1`: A가 B를 팔로우한다.
- `Y_BA = 0`: B는 A를 팔로우하지 않는다.
- `Y_BC = 1`: B가 C를 팔로우한다.

따라서 A→B와 B→A는 서로 다른 관측치다.

이는 방향성 네트워크(Directed Network)의 중요한 특징이다.

### 2.2 가능한 Dyad의 수

자기 자신과의 연결을 제외하면 방향성 네트워크에서 가능한 행위자 쌍의 수는 다음과 같다.

[
N\_{\text{dyads}}=n(n-1)
]

네 명의 의원이 있다면 12개의 방향성 있는 행위자 쌍이 존재한다.

Gopal et al.(2025)은 총 4,108명의 주의원 계정을 분석했다.

따라서 모든 가능한 방향성 있는 관계를 고려하면 다음과 같다.

[
4,108\times4,107=16,871,556
]

약 1,687만 개의 가능한 의원 쌍이 존재하는 것이다.

물론 이는 실제로 연결된 의원 쌍의 수가 아니라, 네트워크에서 연결이 존재할 수 있는 모든 관계의 수다.

### 2.3 네트워크 행렬을 회귀분석 데이터로 변환한다

앞서 제시한 네트워크를 회귀분석을 위한 데이터로 변환하면 다음과 같은 구조가 된다.

| Sender | Receiver | Same Party | Same State | Follow (Y) |
| ------ | -------- | ---------: | ---------: | ---------: |
| A      | B        |          1 |          1 |          1 |
| A      | C        |          0 |          1 |          0 |
| A      | D        |          0 |          0 |          0 |
| B      | A        |          1 |          1 |          0 |
| B      | C        |          0 |          1 |          1 |
| C      | A        |          0 |          1 |          1 |
| D      | B        |          0 |          0 |          1 |

이 표는 설명을 위한 가상의 데이터다.

여기서 종속변수는 의원 간 팔로우 관계의 존재 여부다.

독립변수에는 두 의원이 같은 정당에 속하는지, 같은 주에 속하는지 등의 정보를 포함할 수 있다.

결국 회귀모형을 통해 확인하려는 것은 **특정 속성을 공유하는 두 의원이 서로 연결될 가능성이 더 높은가**라는 질문이다.

## 3. 독립변수: Node-level과 Dyad-level 변수

Gopal et al.(2025)은 회귀분석에서 사용하는 독립변수를 개별 의원의 속성과 의원 간 관계의 속성으로 구분했다.

### 3.1 Node-level Variable: 개별 행위자의 속성

Node-level 변수는 각 의원이 가진 특성이다.

대표적으로 정당, 성별, 인종, 소속 의회 등이 있다.

이러한 변수는 네트워크에서 연결의 방향에 따라 두 가지 효과로 구분할 수 있다.

**Sender Effect(발신자 효과)**

특정 속성을 가진 의원이 다른 의원에게 연결을 보내는 경향을 의미한다.

예를 들어 민주당 의원들이 다른 정당 의원들보다 더 많은 계정을 팔로우하는지 분석할 수 있다.

**Receiver Effect(수신자 효과)**

특정 속성을 가진 의원이 다른 의원들로부터 연결을 받는 경향을 의미한다.

예를 들어 민주당 의원들이 다른 정당 의원들보다 더 많이 팔로우되는지 분석할 수 있다.

이 두 효과는 구분해야 한다.

어떤 의원이 다른 의원들을 적극적으로 팔로우하는 것과, 다른 의원들에게 많이 팔로우되는 것은 서로 다른 현상이기 때문이다.

### 3.2 Dyad-level Variable: 행위자 사이의 관계적 속성

Dyad-level 변수는 두 의원의 속성을 비교해서 구성하는 변수다.

대표적인 예가 \*\*Same Party(정당 유사성)\*\*다.

[
SameParty\_{ij}=
\begin{cases}
1 & Party_i=Party_j\\
0 & Party_i\neq Party_j
\end{cases}
]

두 의원이 같은 정당에 속하면 1, 다른 정당에 속하면 0으로 코딩한다.

같은 방식으로 성별, 인종, 소속 주, 상·하원의 유사성을 측정할 수 있다.

이러한 변수는 네트워크 연구에서 중요한 개념인 \*\*Homophily(동질성 선호)\*\*를 분석하는 데 활용된다.

Homophily는 유사한 속성을 가진 행위자들끼리 연결되는 경향을 의미한다.

### 3.3 Sender, Receiver, Similarity Effect를 구분하는 이유

민주당 의원들 사이에서 팔로우 관계가 많이 관찰되었다고 가정한다.

이러한 결과에는 적어도 세 가지 설명이 가능하다.

1. **Sender Effect:** 민주당 의원들이 전반적으로 다른 의원들을 더 많이 팔로우한다.
2. **Receiver Effect:** 민주당 의원들이 전반적으로 다른 의원들로부터 더 많이 팔로우된다.
3. **Similarity Effect:** 같은 정당에 속한 의원들끼리 특별히 더 많이 연결된다.

세 현상은 서로 다르다.

만약 민주당 의원들이 Twitter를 더 적극적으로 사용한다면, 민주당 의원들 사이에 연결이 많다는 사실만으로 정당 동질성 효과가 강하다고 판단하기 어렵다.

따라서 발신자, 수신자, 의원 간 유사성 변수를 함께 고려하면 이러한 효과를 구분하는 데 도움이 된다.

다만 관찰된 행위자 속성을 통제하는 것만으로 모든 미관측 교란이나 내생성이 해결되는 것은 아니다.

## 4. Logistic Regression과 OLS를 사용하는 이유

Gopal et al.(2025)은 세 가지 네트워크에 서로 다른 회귀모형을 적용했다.

| 네트워크     | 종속변수        | 회귀모형                |
| -------- | ----------- | ------------------- |
| Follower | 팔로우 여부(0/1) | Logistic Regression |
| Retweet  | 리트윗 횟수      | OLS                 |
| Mention  | 멘션 횟수       | OLS                 |

이러한 차이는 종속변수의 측정 방식에서 비롯된다.

### 4.1 Follower Network: Logistic Regression

팔로우 관계는 존재하거나 존재하지 않는 이진변수다.

[
Y\_{ij}^{Follow}\in{0,1}
]

따라서 로지스틱 회귀모형을 사용한다.

[
\log\left(\frac{P(Y\_{ij}=1)}{1-P(Y\_{ij}=1)}\right)
\=\beta_0+\beta_1SameParty\_{ij}+\cdots
]

여기서 `SameParty`의 계수가 양수라면 다른 조건이 동일할 때 같은 정당 소속 의원 간에 팔로우 관계가 존재할 오즈가 더 높다는 의미다.

반대로 음수라면 같은 정당 소속 의원 간의 팔로우 오즈가 더 낮다는 의미다.

주의할 점은 로지스틱 회귀계수 자체가 확률의 증가량을 나타내지 않는다는 것이다.

회귀계수를 지수화한 `exp(β)`가 오즈비(Odds Ratio)가 된다.

### 4.2 Retweet / Mention Network: OLS Regression

리트윗과 멘션 네트워크는 단순한 연결 여부가 아니라 상호작용 횟수를 측정한다.

예를 들어 A가 B의 게시물을 5번 리트윗했다면 해당 관계의 가중치는 5가 된다.

따라서 다음과 같은 선형회귀모형을 사용할 수 있다.

[
Y\_{ij}^{Retweet}
\=\beta_0+\beta_1SameParty\_{ij}
+\beta_2SameGender\_{ij}+\cdots+\epsilon\_{ij}
]

예를 들어 `SameParty`의 회귀계수가 2라면, 다른 조건이 동일할 때 같은 정당 소속 의원 쌍의 예측 리트윗 횟수가 다른 정당 의원 쌍보다 평균 2회 많다는 의미다.

다만 위 계수는 설명을 위한 가상 수치다.

여기서 한 가지 방법론적 의문이 발생한다.

**리트윗과 멘션은 횟수형 변수인데, 왜 Poisson Regression이나 Negative Binomial Regression 대신 OLS를 사용했을까?**

OLS를 횟수형 자료에 적용하는 것 자체가 불가능하지는 않다. 그러나 다음과 같은 한계가 있다.

- 대부분의 의원 쌍에서 리트윗이나 멘션 횟수가 0일 수 있다.
- 일부 의원에게 상호작용이 집중되어 분포가 심하게 비대칭적일 수 있다.
- 선형회귀모형에서는 음수의 예측값이 나올 가능성이 있다.

따라서 횟수형 네트워크를 분석할 때는 종속변수의 분포를 확인하고, 필요하다면 Poisson이나 Negative Binomial 같은 대안적 모형을 검토할 수 있다.

Gopal et al.(2025)은 OLS와 QAP를 사용했지만, 본문에서 대안적인 횟수형 회귀모형과 상세하게 비교하지는 않았다.

## 5. Network Dependence: 일반 회귀분석에서 무엇이 문제가 되는가?

네트워크 자료를 분석할 때 중요한 문제 중 하나는 \*\*Network Dependence(네트워크 의존성)\*\*다.

일반적인 회귀분석에서는 통계적 추론을 위해 오차항 간 독립성 또는 이에 상응하는 적절한 공분산 가정이 필요하다.

하지만 네트워크에서는 각각의 관측치가 서로 독립적이지 않을 가능성이 크다.

대표적으로 다음 세 가지 사례를 생각할 수 있다.

### 5.1 Shared Actor Dependence: 동일한 행위자를 공유하는 관계

```text
       ┌────→ B
       │
       A
       │
       └────→ C
```

A→B와 A→C는 모두 발신자 A를 공유한다.

만약 A가 원래 다른 사람을 많이 팔로우하는 의원이라면, 두 연결이 존재할 가능성은 서로 관련되어 있을 수 있다.

따라서 A→B와 A→C를 완전히 독립적인 관측치로 취급하기 어렵다.

### 5.2 Reciprocity: 상호성

```text
       ─────→
    A          B
       ←─────
```

A가 B를 팔로우한다면 B도 A를 팔로우할 가능성이 있다.

이처럼 A→B와 B→A의 연결이 서로 관련되는 현상을 상호성이라고 한다.

### 5.3 Transitivity: 이행성 또는 삼각적 폐쇄

```text
    A ─────→ B
     ·       │
      ·      │
       ·     ↓
         →   C

    A → C : 추가 연결 가능성
```

A가 B와 연결되어 있고 B가 C와 연결되어 있다면, A 역시 C와 연결될 가능성이 높아질 수 있다.

이러한 구조적 의존성은 흔히 친구의 친구가 친구가 되는 현상으로 설명된다.

Gopal et al.(2025)이 Dorff and Ward(2013)를 인용하면서 언급한 네트워크 의존성도 이러한 맥락에서 이해할 수 있다.

### 5.4 네트워크 의존성을 무시하면 생기는 문제

예를 들어 민주당 의원들 사이에 매우 많은 연결이 발견되었다고 가정한다.

일반 회귀분석에서는 이러한 연결 각각을 독립적인 정보로 취급할 수 있다.

그러나 실제로는 영향력이 큰 민주당 의원 한 명이 많은 다른 의원과 관계를 맺었기 때문에 연결이 집중되었을 가능성도 있다.

이런 경우 연결이 많다는 사실이 그만큼 많은 독립적인 증거를 확보했다는 뜻은 아니다.

네트워크 의존성을 고려하지 않으면 다음과 같은 문제가 발생할 수 있다.

**첫째, 표준오차가 부적절하게 추정될 수 있다.**

관측치 사이에 의존성이 존재하는데 이를 무시하면 회귀계수의 통계적 유의성을 잘못 평가할 수 있다.

예를 들어 실제보다 표준오차를 작게 추정하면 유의하지 않은 관계를 유의한 것으로 판단할 위험이 있다.

**둘째, 회귀계수 자체에도 편향이 발생할 수 있다.**

다만 네트워크 의존성이 존재한다고 해서 반드시 회귀계수가 편향되는 것은 아니다.

설명변수와 관련된 중요한 구조적 요인이 누락되거나 내생성이 존재할 때 계수 편향 문제가 발생할 수 있다.

따라서 오차항의 의존성과 설명변수의 내생성은 구분해야 한다.

## 6. QAP: 네트워크 의존성을 어떻게 고려하는가?

### 6.1 QAP의 기본 개념

\*\*QAP(Quadratic Assignment Procedure)\*\*는 네트워크 행렬의 노드를 재배열하는 순열검정(Permutation Test)에 기반한 통계적 추론 방법이다.

일반적인 회귀분석에서는 추정된 회귀계수와 표준오차를 이용하여 p-value를 계산한다.

반면 QAP는 실제로 관찰된 통계량을 네트워크 행렬을 반복적으로 재배열했을 때 나타나는 통계량의 분포와 비교한다.

핵심은 네트워크 내부의 연결 구조를 보존하면서, 네트워크와 행위자 속성 사이의 관찰된 관계가 얼마나 이례적인지를 평가한다는 점이다.

QAP의 기본적인 절차는 다음과 같다.

```text
[1] 실제 네트워크 데이터
          ↓
[2] 원래 회귀계수 추정
          ↓
[3] 네트워크 노드 순서 재배열
          ↓
[4] 재배열된 데이터에서 통계량 계산
          ↓
[5] 순열 및 계산 반복
          ↓
[6] 순열분포 생성
          ↓
[7] 실제 통계량과 순열분포 비교
          ↓
[8] QAP p-value 계산
```

### 6.2 Step 1: 실제 데이터에서 회귀계수를 추정한다

먼저 실제 관찰된 네트워크에서 회귀모형을 추정한다.

예를 들어 동일 정당 여부를 나타내는 `SameParty`의 회귀계수가 0.8이라고 가정한다.

[
\hat{\beta}\_{observed}=0.8
]

이는 실제 데이터에서 관찰된 회귀계수다.

그러나 이 값만으로 네트워크 의존성을 고려했을 때도 통계적으로 유의한 관계인지 판단할 수는 없다.

### 6.3 Step 2: 네트워크 행렬을 재배열한다

QAP의 기본형에서는 네트워크 행렬의 행과 열을 동일한 순서로 함께 재배열한다.

[
Y^{\*}=PYP^{T}
]

여기서 각 기호의 의미는 다음과 같다.

- `Y`: 원래 네트워크 행렬
- `P`: 노드 순서를 바꾸는 순열행렬
- `Y*`: 재배열된 네트워크 행렬

중요한 것은 개별 연결을 무작위로 새롭게 생성하는 것이 아니라는 점이다.

노드의 순서를 바꿀 뿐이므로 네트워크 내부의 구조적 특징은 보존된다.

예를 들어 특정 의원에게 연결이 집중된 정도, 상호성, 삼각적 연결 구조는 유지된다.

반면 고정된 의원 속성 데이터와 네트워크 연결 사이의 대응 관계가 바뀐다.

이를 통해 네트워크 내부의 의존구조를 유지하면서 설명변수와 네트워크 연결 사이의 관계를 검정할 수 있다.

다만 이러한 설명은 QAP의 기본 원리를 단순화한 것이다. 실제 다중회귀 QAP에는 여러 순열 방식이 존재한다.

### 6.4 Step 3: 반복해서 새로운 통계량을 계산한다

이러한 재배열을 수백 번 또는 수천 번 반복할 수 있다.

매번 재배열된 데이터에서 통계량을 계산하면 귀무가설하에서 비교할 수 있는 순열분포가 생성된다.

예를 들어 999번의 순열을 수행했다고 가정한다.

실제로 관찰된 회귀계수의 절댓값보다 같거나 더 극단적인 값이 14번 나타났다면, 단순화한 양측 순열 p-value는 다음과 같이 계산할 수 있다.

[
p=\frac{14+1}{999+1}=0.015
]

이 경우 p-value는 0.015이므로 일반적인 5% 유의수준에서 귀무가설을 기각한다.

즉, 관찰된 회귀계수가 해당 순열검정의 귀무분포에서 상대적으로 드물게 나타난다는 의미다.

이 수치는 QAP의 원리를 설명하기 위한 가상의 예시이며, Gopal et al.(2025)의 실제 분석 결과는 아니다.

### 6.5 QAP와 MRQAP의 차이

QAP와 MRQAP는 관련된 방법이지만 정확하게 같은 의미는 아니다.

**QAP**는 기본적으로 두 관계행렬 사이의 연관성을 평가하는 순열검정 방식이다.

반면 \*\*MRQAP(Multiple Regression Quadratic Assignment Procedure)\*\*는 여러 설명변수를 포함한 회귀모형에서 회귀계수의 유의성을 검정하는 접근이다.

MRQAP에는 여러 변형이 존재한다.

| 방법                           | 특징                                     |
| ---------------------------- | -------------------------------------- |
| Raw-data Permutation         | 관계행렬의 원자료를 재배열한다.                      |
| Freedman–Lane                | 다른 설명변수의 효과를 고려한 잔차 기반 순열검정을 수행한다.     |
| Double Semi-Partialing (DSP) | 설명변수 간 상관을 고려하도록 설계된 잔차 기반 순열방식을 사용한다. |

Dekker, Krackhardt, and Snijders(2007)는 다중회귀 QAP에서 다중공선성과 자기상관 조건에 따른 여러 검정 방식의 성능을 비교했다.

Gopal et al.(2025)도 해당 연구를 인용한다.

다만 Gopal et al.(2025)의 본문에 제시된 방법론 설명만으로는 정확한 순열 방식과 반복 횟수를 확인하기 어렵다.

따라서 일반적인 QAP의 원리와 실제 연구에서 사용된 구체적인 구현 방식은 구별할 필요가 있다.

## 7. QAP는 네트워크 의존성을 직접 모델링하는 방법인가?

여기서 반드시 구분해야 할 부분이 있다.

**QAP를 사용한다는 것은 네트워크 의존성을 고려한 유의성 검정을 수행한다는 의미이지, 네트워크의 구조적 메커니즘을 직접 추정한다는 의미는 아니다.**

예를 들어 다음과 같은 질문을 생각할 수 있다.

> A가 B를 팔로우하고 B가 C를 팔로우하기 때문에, A가 C를 팔로우할 가능성이 얼마나 높아지는가?

이 질문은 네트워크에서 삼각적 폐쇄가 연결 형성에 어떤 역할을 하는지에 관한 것이다.

이를 직접 분석하려면 삼각적 폐쇄와 같은 구조적 메커니즘을 모형에 포함해야 한다.

반면 QAP는 이미 존재하는 네트워크의 의존구조를 고려하여 통계적 유의성을 평가한다.

두 접근은 서로 다르다.

| 분석 요소                     | Gopal et al.(2025)에서의 역할    |
| ------------------------- | --------------------------- |
| Logistic Regression / OLS | 의원 간 연결과 설명변수 사이의 관계 추정     |
| Sender / Receiver Effect  | 개별 의원의 발신·수신 속성 분석          |
| Similarity Effect         | 의원 간 동질성과 연결의 관계 분석         |
| Interaction Effect        | 동일 주 내부와 주 간 관계에서 효과의 차이 검토 |
| QAP                       | 네트워크 의존성을 고려한 통계적 유의성 검정    |
| Transitivity 직접 추정        | 별도의 구조적 메커니즘으로 직접 추정하지 않음   |
| Causal Inference          | 연결 형성의 인과효과를 식별하지 않음        |

QAP를 사용한다고 해서 회귀계수가 자동으로 불편추정량이 되는 것도 아니다.

설명변수의 내생성이나 누락변수 문제는 별도로 검토해야 한다.

## 8. 실제 분석 사례: Follower Network의 정당 동질성 효과

Gopal et al.(2025)의 Figure 4에서는 팔로우 네트워크에 대한 회귀분석과 QAP 검정 결과를 제시한다.

연구진은 정당, 성별, 인종, 소속 의회의 유사성이 의원 간 연결과 어떤 관계를 가지는지 분석했다.

특히 동일한 주에 속한 의원들 사이의 관계와 서로 다른 주에 속한 의원들 사이의 관계를 구분했다.

이러한 상호작용 모형의 기본 구조를 단순화하면 다음과 같다.

[
\begin{aligned}
\operatorname{logit}(p\_{ij})={}&\beta_0\\
&+\beta_1(SameParty\_{ij}\times SameState\_{ij})\\
&+\beta_2(SameParty\_{ij}\times DifferentState\_{ij})\\
&+\cdots
\end{aligned}
]

실제 연구에서는 이외에도 다양한 의원 속성과 관계적 설명변수가 포함된다.

Figure 4에서 같은 정당 소속이라는 속성의 회귀계수는 다음과 같다.

| 정당 동질성 효과 |  회귀계수 |
| --------- | ----: |
| 동일 주 내부   | 1.438 |
| 서로 다른 주   | 2.313 |

두 계수는 모두 양수다.

즉, 같은 정당에 속한 의원들끼리 팔로우 관계를 형성하는 경향이 있으며, 해당 회귀계수는 서로 다른 주에 속한 의원들 사이에서 더 크게 나타난다.

여기서 회귀계수는 로지스틱 회귀모형의 로그오즈 계수다.

따라서 1.438이나 2.313을 팔로우 확률의 증가량으로 직접 해석해서는 안 된다.

또한 두 계수가 각각 유의하다는 사실과 두 계수의 차이가 통계적으로 유의하다는 사실은 별개의 문제다.

Gopal et al.(2025)은 각주 4에서 QAP와 같은 순열 기반 방법으로는 통상적인 공분산행렬이 추정되지 않으므로, 조건부 효과의 유의성을 평가하기 위해 동일 주와 상이 주 지표를 이용한 상호작용 모형을 각각 추정했다고 설명한다.

따라서 두 계수의 크기를 비교하는 것과 두 계수의 차이에 대한 통계적 검정을 수행하는 것은 구별해야 한다.

## 9. Dyadic Regression + QAP와 다른 네트워크 분석 방법론 비교

네트워크를 분석하는 통계적 방법은 다양하며, 연구 질문에 따라 적합한 접근이 달라진다.

| 방법론                     | 주요 분석 대상            | 핵심 질문                                         |
| ----------------------- | ------------------- | --------------------------------------------- |
| Dyadic Regression + QAP | 행위자 속성과 연결의 관계      | 같은 속성을 가진 행위자들이 더 많이 연결되는가?                   |
| ERGM                    | 네트워크의 구조적 메커니즘      | 동질성, 상호성, 삼각적 폐쇄가 네트워크 구조와 어떻게 관련되는가?         |
| SAOM / RSiena           | 시간에 따른 네트워크와 행동의 변화 | 어떤 행위자가 누구와 연결되며, 네트워크와 행동은 어떻게 함께 변화하는가?     |
| Relational Event Model  | 시간 순서가 있는 관계적 사건    | 누가 누구와 언제 상호작용하며, 이전 사건은 후속 상호작용과 어떤 관계를 갖는가? |

**Dyadic Regression + QAP**는 특정 속성이 행위자 간 연결과 어떤 관계를 갖는지 분석하는 데 적합하다.

\*\*ERGM(Exponential Random Graph Model)\*\*은 행위자 속성뿐 아니라 상호성이나 삼각적 폐쇄처럼 네트워크 내부에서 발생하는 구조적 메커니즘을 모형에 직접 포함할 수 있다.

\*\*SAOM(Stochastic Actor-Oriented Model)\*\*은 여러 시점에서 관찰된 네트워크를 이용하여 연결의 생성과 소멸, 행위자 행동의 변화를 분석한다.

\*\*REM(Relational Event Model)\*\*은 사건의 발생 시각과 순서를 이용하여 행위자 간 상호작용이 어떤 조건에서 발생하는지 분석한다.

이 방법들은 서로 완전히 배타적인 접근이 아니다. 분석 대상이 정적인 연결인지, 네트워크 구조인지, 시간에 따른 관계 변화인지, 개별 상호작용 사건인지에 따라 선택할 수 있다.

## 10. 정리

Gopal et al.(2025)의 네트워크 회귀분석에서 가장 중요한 특징은 **행위자 개인이 아니라 두 행위자 사이의 연결을 종속변수로 설정했다는 점**이다.

연구진은 정당, 성별, 인종, 소속 의회와 같은 의원의 속성뿐 아니라 두 의원 사이의 유사성을 독립변수로 구성했다.

팔로우 네트워크에는 로지스틱 회귀분석을, 리트윗과 멘션 네트워크에는 OLS를 적용했다.

그리고 각각의 네트워크에서 관측치 간 의존성이 존재한다는 문제를 고려하기 위해 QAP를 활용하여 통계적 유의성을 검정했다.

이러한 방법론을 이해할 때는 세 가지를 구분해야 한다.

첫째, **회귀모형은 행위자 속성과 연결 사이의 관계를 추정한다.**

둘째, **QAP는 네트워크 의존성을 고려하여 통계적 유의성을 평가한다.**

셋째, **QAP를 사용했다는 사실만으로 네트워크의 구조적 메커니즘이나 인과관계를 직접 추정했다고 볼 수는 없다.**

결국 Gopal et al.(2025)의 방법론은 네트워크를 단순히 시각화하는 수준을 넘어, 행위자 간 연결을 설명하려는 통계적 접근의 한 사례로 이해할 수 있다.
